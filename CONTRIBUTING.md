# Contributing

Bug reports and focused pull requests are welcome.

Before opening an issue, include:

- Redmine, Ruby, Rails, and database versions;
- plugin version or commit;
- exact reproduction steps;
- expected and actual behavior;
- relevant sanitized logs.

Never include API keys, credentials, personal data, or internal URLs.

For code changes:

1. Keep Redmine core files untouched.
2. Add or update tests when the repository contains a test suite.
3. Run the relevant tests in a clean Redmine installation.
4. Update the changelog for user-visible changes.
5. Keep one logical change per pull request.
