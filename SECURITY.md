# Security policy

Do not publish suspected vulnerabilities in a public issue before a fix is available.

Use the repository's private security advisory feature to report:

- authentication or authorization bypasses;
- cross-site scripting or request-forgery issues;
- SQL injection or unsafe deserialization;
- exposure of credentials or personal data;
- any flaw that can modify Redmine data without the expected permission.

Include the affected version, impact, reproduction steps, and a minimal proof of concept. Remove real credentials and personal information from the report.
