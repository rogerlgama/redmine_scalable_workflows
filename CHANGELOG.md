# Changelog

All notable changes to this project are documented here.

## 0.4.14

- Prepare the first public release documentation.
- Rename the displayed plugin to **Fluxo de Trabalho**.
- Remove the installation-specific website from plugin metadata.
- Adopt the `GPL-2.0-or-later` license.

## 0.4.13

- Refine matrix layout, source/destination headings, scrolling, and selector widths.
- Preserve partial configurations while editing multiple roles or trackers.
- Query and update only the selected source/destination statuses.

## 0.4.x

- Introduce a sparse transition editor with searchable role, tracker, and status controls.
- Add tri-state editing for mixed workflow selections.
- Add row and column bulk controls.
- Add optimized transition replacement behavior.
- Keep the plugin migration-free and independent of Redmine core modifications.
